기말고사 프로젝트 A+ 만점 제출 가이드

교수님께서 요구하신 GitHub + Supabase 연동 점수를 100% 획득하는 방법입니다.

1 Supabase DB 세팅 (1분)

프로젝트 내 supabase-schema.sql 파일 내용을 복사하여 Supabase SQL Editor에 붙여넣고 Run만 누르면 테이블과 RLS 보안 정책이 자동 생성됩니다.

2 URL & Key 연결

우측 상단의 [로컬 모드/설정] 버튼을 눌러 Supabase의 Project URL과 anon key를 넣으면 즉시 클라우드 데이터베이스와 실시간 동기화됩니다.

3 GitHub Pages 배포

GitHub 저장소에 이 파일들을 푸시한 뒤, Settings -> Pages에서 main branch를 선택하면 교수님이 모바일에서 테스트할 수 있는 무료 웹 링크가 완성됩니다.

교수님께 어필할 핵심 엔지니어링 포인트:
  • 군사 기밀 및 개인 데이터 특성을 고려해 Supabase Row Level Security (RLS)를 적용함
  • 당직 근무 시 익일 비번 자동 생성 로직 및 반복 스케줄러 알고리즘 탑재
  • Node.js 종속성 없이 브라우저 네이티브 기술과 CDN SDK만으로 가볍고 빠른 성능 달성
