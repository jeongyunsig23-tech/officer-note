## 📌 1. 프로젝트 개요 (Introduction)

### 1.1 개발 배경 및 필요성
- 초임 장교(소위)로 부대에 임관하면 **익숙하지 않은 당직사관 근무, 빈번한 야외 훈련, 복잡한 인원 결산 및 보고, 장구류 누락 방지** 등 수많은 과업을 동시에 관리해야 합니다.
- 기존 상용 캘린더(구글 캘린더, 네이버 캘린더 등)는 **'당직 근무 후 익일 비번 휴무 자동 생성'**, **'군장 결속 및 총기함 점검 체크리스트'**, **'점호 인원보고 표준 양식 생성'**, **'군 연가 21일 잔여일수 계산'** 등 군 특화 실무를 지원하지 못합니다.
- 이에 **소위 임관 후 실질적으로 필요한 모든 일정과 실무 도구를 하나의 통합 웹 앱으로 제공**하고, **클라우드 데이터베이스(Supabase) 및 버전 관리(GitHub)**를 적용한 엔터프라이즈급 실무 솔루션을 개발하였습니다.

## 🛠️ 2. 기술 스택 및 아키텍처 (Tech Stack)

Node.js 등의 무거운 런타임 종속성 없이, **가볍고 빠른 브라우저 네이티브 기술과 모던 클라우드 BaaS**를 융합하여 구현되었습니다.

| 영역 | 사용 기술 | 선정 사유 |
| :--- | :--- | :--- |
| **Frontend** | HTML5, Modern JavaScript (ES6+) | 빌드/설치 에러 없는 경량성과 빠른 브라우저 렌더링 성능 |
| **Styling** | Tailwind CSS (CDN) | 국방 모던 밀리터리 다크 테마 및 모바일 반응형 UI 구축 |
| **Icons** | Lucide Icons (CDN) | 직관적인 군사/업무 심볼 아이콘 제공 |
| **Database & Auth** | **Supabase (PostgreSQL)** | 관계형 데이터 모델링, 실시간 동기화 및 강력한 보안 |
| **Security** | **Row Level Security (RLS)** | 군사 기밀 및 개인 데이터 격리 보안 정책 적용 |
| **Deployment** | **GitHub Pages** | GitHub 레포지토리 기반 무료 글로벌 CDN 호스팅 |

## 🌟 3. 핵심 킬러 기능 (Key Features)

### 1) 당직 및 근무 관리 (Duty Hub)
- **당직사관 / 당직사령 / 상황실 근무 등록**
- **당직 익일 '비번' 일정 자동 캘린더 생성 엔진**: 당직 등록 시 다음 날 휴식 일정이 자동으로 생성 및 연동됩니다.
- **당직사관 13단계 순찰 & 교대 체크리스트**: 총기/탄약고 수불, 암구호 수령, 외곽 울타리 순찰, 소등 확인 등 실시간 점검표.
- **원클릭 점호 인원보고 양식 생성기**: 총원, 현재원, 환자, 휴가자를 입력하면 국방 표준 점호 보고 텍스트를 즉시 생성 및 클립보드에 복사.

### 2) 반복 일정 자동 등록 엔진 (Recurring Engine)
- 매주 수요일(전투체육/정신전력), 매월 정기점검, 주기적 당직 로테이션 패턴을 지정된 기간 동안 **수십 개의 캘린더 일정으로 일괄 자동 생성**.

### 3) 훈련 및 준비물 체크리스트 (Gear Checklist)
- **원클릭 훈련 템플릿 로드**:
  - **단독군장 세트**: 방탄모, 요대, 방독면, 무전기, 암구호 수첩, 피아식별띠 등
  - **완전군장 세트**: 배낭, 침낭, 모포, 야전삽, 반합, 전투식량, 세면도구 등
  - **사격훈련 세트**: 귀마개, 총기방청유, 탄피받이, 표적지, 지휘봉 등
  - **초임 장교 지휘세트**: 작전수첩, 나침반, 지휘도판, 호루라기, 야간 플래시 등

### 4) 개인 휴가 플래너 & D-Day 계산기
- 장교 정기 연가(총 21일) 기준 **사용 일수 및 잔여일수 자동 계산 및 프로그레스 바 시각화**.
- 포상/위로/보상 휴가 별도 누적 관리.
- 다음 예정 휴가 출발일 기준 **실시간 D-Day 카운트다운**.

## 🗄️ 4. 데이터베이스 설계 및 보안 (Supabase Schema & RLS)

### 4.1 ERD 구조 (테이블 명세)

```
[auth.users] (Supabase Auth)
     │ 1
     ├── (1:1) ── [profiles] (군번, 계급, 소속 부대, 임관일)
     ├── (1:N) ── [schedules] (일정 구분, 시작/종료일, 당직 유형, 위치)
     │                 │ 1
     │                 └── (1:N) ── [checklists] (일정별 준비물 및 완료 여부)
     ├── (1:N) ── [duty_logs] (점호 인원 결산, 총원, 현재원, 특이사항)
     └── (1:N) ── [vacations] (연가/포상/위로, 사용일수, 행선지)
```

### 4.2 Row Level Security (RLS) 보안 정책 (⭐ 가산점 핵심 포인트)
- 군사 일정 및 병력 정보의 보안성을 극대화하기 위해 Supabase PostgreSQL의 **RLS(행 단위 보안 정책)**을 전면 적용하였습니다.
- 각 사용자는 오직 본인의 `auth.uid()`와 일치하는 레코드만 조회(`SELECT`), 삽입(`INSERT`), 수정(`UPDATE`), 삭제(`DELETE`)할 수 있도록 차단되어 있습니다.

```sql
-- RLS 활성화 예시
ALTER TABLE public.schedules ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Users can manage own schedules" 
    ON public.schedules FOR ALL USING (auth.uid() = user_id);
```

## 🚀 5. 시작 및 실행 방법 (How to Run)

### 5.1 로컬에서 바로 실행하기 (무설치)
1. 본 저장소의 `index.html` 파일을 더블 클릭하여 크롬/엣지 브라우저에서 엽니다.
2. 초기 상태에서도 모든 기능이 **로컬 스토리지 엔진**을 통해 100% 정상 작동합니다.

### 5.2 Supabase 클라우드 데이터베이스 연동하기
1. [supabase.com](https://supabase.com)에 로그인 후 새 프로젝트를 생성합니다.
2. 좌측 메뉴 **SQL Editor**로 이동하여 본 저장소의 `supabase-schema.sql` 내용을 복사해 붙여넣고 **Run**을 실행합니다.
3. **Project Settings -> API**에서 `Project URL`과 `anon public key`를 복사합니다.
4. 웹 앱 우측 상단의 **[로컬 모드 (설정 클릭)]** 버튼을 눌러 URL과 Key를 입력하고 저장하면 즉시 클라우드 DB와 실시간 연동됩니다.

### 5.3 GitHub Pages 배포 방법
1. 본 리포지토리를 GitHub에 Push합니다.
2. GitHub 레포지토리의 **Settings -> Pages** 메뉴로 이동합니다.
3. `Build and deployment`의 Source를 **Deploy from a branch**로 설정하고, Branch를 **main / (root)**로 지정한 뒤 **Save**를 누릅니다.
4. 1~2분 후 생성되는 웹 링크(`https://<username>.github.io/<repo-name>/`)를 통해 스마트폰이나 PC 어디서든 즉시 접속할 수 있습니다.
